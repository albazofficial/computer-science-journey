# 01 — What Is Computer Science?

## Definition

Computer Science is the study of computation, information, algorithms, and the principles used to design and understand computational systems.

It includes much more than writing code. It also studies how problems can be represented, how solutions can be designed, and how computers process information.

## Core Areas

### 1. Algorithms

An algorithm is a finite, well-defined sequence of steps for solving a problem or completing a task.

Example: An algorithm for finding the largest number in a list.

1. Start with the first number as the current maximum.
2. Compare it with each remaining number.
3. Replace the current maximum whenever a larger number is found.
4. Return the maximum after checking every number.

### 2. Data Representation

Computers represent and process information using binary digits: `0` and `1`.

Numbers, text, images, and other forms of information can be encoded into representations that computer systems can process.

### 3. Computer Systems

Computer systems combine hardware and software.

- Hardware refers to physical components.
- Software refers to programs and instructions executed by a computer.

### 4. Programming

Programming is the process of expressing instructions in a programming language so that a computer can perform tasks.

Programming is an important tool in Computer Science, but the two terms are not interchangeable.

### 5. Artificial Intelligence

Artificial Intelligence is a field concerned with building systems that perform tasks associated with capabilities such as learning, reasoning, perception, and language understanding.

AI draws on several areas, including algorithms, mathematics, statistics, and computer systems.

## Computer Science vs. Programming

| Computer Science | Programming |
|---|---|
| Studies computational principles and problem-solving methods. | Implements instructions using programming languages. |
| Includes algorithms, data representation, and computer architecture. | Includes writing, testing, and maintaining code. |
| Can be studied theoretically or practically. | Is primarily a practical activity, supported by theory. |

## Key Takeaways

- Computer Science is broader than programming.
- Algorithms describe procedures for solving problems.
- Computers process information using defined representations.
- Programming helps implement computational solutions.
- AI builds on concepts from several areas of Computer Science.
