
# Computer Science Journey

A structured, project-based journey through Computer Science, starting from the fundamentals and progressing toward Artificial Intelligence Engineering.

## Purpose

This repository documents my learning process through clear notes, practical exercises, experiments, and small projects.

The goal is to develop a strong understanding of how computers work, how software is built, and how the foundations of Computer Science lead to Artificial Intelligence.

## Learning Roadmap

1. Computer Science fundamentals
2. Computer hardware and architecture
3. Binary numbers and data representation
4. Operating systems and how software runs
5. Algorithms and computational thinking
6. Python programming
7. Data structures and algorithms
8. Mathematics for Artificial Intelligence
9. Machine Learning
10. Deep Learning and Neural Networks
11. Transformers and Large Language Models
12. AI Engineering and model training

This roadmap will evolve as my knowledge and understanding grow.

- Record mistakes and corrections.
- Keep the progress log accurate and up to date.
